🏛️ Deliverable 1: Pillar Choices (Day 8 Base)

For this enterprise knowledge assistant, we selected Retrieval-Augmented Generation (RAG) and Continuous Evaluation & Guardrails as our two primary pillars. RAG is required because our enterprise documentation updates dynamically and demands deterministic grounding without costly retraining. Continuous Evaluation & Guardrails are essential because user-facing accuracy requires real-time hallucination prevention and automated rollback triggers to maintain strict regulatory compliance.

🛡️ Deliverable 2: Critical Failure Point (Day 8 Advanced)

The most critical failure point is an ungrounded hallucination bypassing the evaluation guardrail, which directly damages institutional credibility and user trust. To mitigate this, the architecture enforces a deterministic citation-grounding validation layer where generated statements must link to explicit retrieved chunk IDs verified via Natural Language Inference (NLI) and regex pattern matching before rendering. Any output failing this strict threshold is intercepted and replaced by a deterministic, pre-approved safe response ("I cannot verify this information based on the available data.").

🚨 3 Explicit Fallbacks

  • Retriever Failure (< 0.70): Routes query to external search agent (SerpAPI) to retrieve and embed fresh web documents.
  • Token Limit Exceeded (> 80%): Intercepted by middleware and compressed via Map-Reduce summarization using a lightweight model.
  • Eval Gate Rejection: NLI faithfulness judge rejects ungrounded drafts and immediately returns a deterministic safe response.

⚡ Scaling the Reranker

  • First Bottleneck: Cross-Encoder Reranker bottlenecking on quadratic cross-attention O(K × L²), exhausting GPU VRAM and blocking async loops.
  • Queue Decoupling: Candidate sets are offloaded to an asynchronous Redis/Celery queue with dynamic KEDA worker autoscaling on GPU nodes.
  • Semantic Caching: High-similarity queries (≥ 0.95) return cached answers in <15ms with zero GPU usage.

📈 Eval Telemetry & Rollback

  • Eval Collector Siting: Sits inline post-generation, scoring faithfulness before text reaches the user.
  • Goodhart's Law Alert: A refusal rate spike >15% while faithfulness is high triggers a PagerDuty P1 incident.
  • Automated Rollback: A drop in faithfulness below 0.85 triggers an automated CI/CD webhook to roll back to the golden release.
